How to Build the NOVA C-IDE
by Team NOVA

First edition, 2026.

NOVA IDE is an in-house tool. This book describes how it was built so that anyone on the team can understand it, rebuild it, change it and grow it.

All screenshots in this book were taken from the real NOVA IDE running on Windows 11 and were converted to black and white for printing. Every code sample marked with an OUTPUT box was compiled and run while this book was being made, so the output you see is the real output.

Trademarks: CLion and JetBrains are trademarks of JetBrains s.r.o. NOVA was designed from public documentation and its own ideas. It contains no JetBrains code. Visual Studio Code, Monaco, Electron, xterm.js, clangd, LLVM, GDB, CMake and other names belong to their respective owners.
